A Catalogue of Observability and Evaluation Metrics for AI Agents

Tools that trace and evaluate AI agents each ship their own metrics, under their own names. We read the documentation of 13 tools and the 3 telemetry standards beneath them, recorded every metric they ship out of the box, and merged the equivalent ones into 46 unique metrics. Each one is defined here and linked to the pages that document it.

Taxonomy

Every metric is classified on two levels. The type says where its value comes from: it is either recorded during the run or assigned afterwards by a judge. The category says which part of the run it is about. Tool use and plan and trajectory appear under both types, because the same part of a run can be counted or judged.

Bars show how many of the 13 tools ship the metric (standards are not counted). Select a metric to open its entry.

Method

Choosing the tools

Most tools are documented in repositories, vendor pages and blogs, so we searched GitHub and Google with fixed queries on 22 Oct 2026 and screened the results by hand against written inclusion and exclusion rules. The OpenTelemetry conventions for generative AI were added by hand, since a standard has no product page for such queries to rank.

Collecting the metrics

For each tool we read the official documentation and recorded every built-in metric: one the tool itself ships, as opposed to a metric the user writes, a community contribution or one reached through an integration. We kept the metrics that describe how an agent run executes or how good its output is. Each of the 297 rows stores the page, a verbatim quote, a saved copy of the page and the date, and a script checks that every quote appears word for word in the saved copy.

Merging them

Two metrics from different tools become one unique metric when they measure the same thing about the same object, whatever the tools call them. The mapping (376 pairs) is made by hand. The definitions on this site are ours, not quotations.

Reading the catalogue with care

  • Tools that share a unique metric may compute it differently, and can disagree on the same run.
  • An empty cell means we found nothing in the pages we read. It does not prove the tool lacks the metric.
  • Documentation changes. Every quote carries the date its page was read.
  • Text-match and format checks, retrieval scores, audio, voice and image metrics and task-specific metrics are out of scope.
  • Closed-source tools that the search results did not name are absent.
