A Catalogue of Observability and Evaluation Metrics for AI Agents

Tools that trace and evaluate AI agents each ship their own metrics, under their own names. We read the documentation of 13 tools and the 3 sets of telemetry conventions beneath them, recorded every metric they ship out of the box, and merged the equivalent ones into 46 unique metrics. Each one is defined here and linked to the pages that document it.

Taxonomy

Every metric is classified on two levels. The type says where its value comes from: it is either recorded during the run or assigned afterwards by a judge. The category says which part of the run it is about. Tool use and plan and trajectory appear under both types, because the same part of a run can be counted or judged.

Bars show how many of the 13 tools ship the metric (the telemetry conventions are not counted). Select a metric to open its page.
