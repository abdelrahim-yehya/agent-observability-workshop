# Langfuse Changelog

- [Launch](https://langfuse.com/changelog/2023-07-19-launch.md): After working on the initial version for 2 months, we are excited to launch Langfuse today!
- [Nested traces](https://langfuse.com/changelog/2023-07-24-nested-trace-ui.md): New user interface to browse complex traces in a nested way.
- [Langchain integration (Python)](https://langfuse.com/changelog/2023-07-27-integration-langchain-python.md): LLM applications/chains/agents running on Langchain can now be traces via the native integration.
- [User management](https://langfuse.com/changelog/2023-07-27-project-user-management.md): Share projects with coworkers and manage permissions.
- [GET API for usage tracking](https://langfuse.com/changelog/2023-08-07-extended-usage-get-api.md): Get usage data from Langfuse API for use in your own application and dashboards. Optionally broken down by user or use case.
- [Public access to Q&A chatbot project](https://langfuse.com/changelog/2023-08-14-public-demo-project.md): We've built the Q&A chatbot for the Langfuse docs, now everyone can access its production traces. Create an account on Langfuse Cloud and play with the Q&A chatbot to see your own traces.
- [🐳 Prebuilt Docker images](https://langfuse.com/changelog/2023-08-16-prebuilt-docker-image.md): Self-hosting is now easier than ever with our prebuilt Docker images.
- [Langchain integration (Javascript)](https://langfuse.com/changelog/2023-08-30-integration-langchain-js.md): Now the Langchain integration is also available for Javascript.
- [Share traces via public link](https://langfuse.com/changelog/2023-09-14-public-link-sharing.md): You can now make your traces public to discuss them with your team or share them more publicly.
- [New JSON viewer](https://langfuse.com/changelog/2023-09-27-JSON-viewer.md): Inputs and outputs of spans and generations can be complex, now it is much easier to read them. Click to copy any value.
- [Complex filters](https://langfuse.com/changelog/2023-10-03-complex-filters.md): Use the new filter builder to filter across all sorts of attributes. State is persisted in the URL, so you can share your filters with others.
- [Navigate quickly between traces](https://langfuse.com/changelog/2023-10-05-faster-navigation.md): Browse traces and users super-⚡️. Jump between traces with keyboard shortcuts (k & j).
- [Improved support of complex inputs and outputs (e.g. OpenAI functions)](https://langfuse.com/changelog/2023-10-07-improved-support-of-complex-inputs-and-outputs.md): If you pass JSON as a completion, it is rendered in the Langfuse UI.
- [Ingestion APIs now 2x faster](https://langfuse.com/changelog/2023-10-19-doubled-performance-ingestion-apis.md): We've removed a performance bottleneck in the API authentication which affected all API requests.
- [Python SDK now supports Pydantic v1 and v2](https://langfuse.com/changelog/2023-10-25-support-pydantic-v1-and-v2.md): The Python SDK uses Pydantic to validate the data you send to Langfuse at run time before it is asynchronously sent to the Langfuse API. Previously, the Python SDK used Pydantic v1 leading to incompatibilities with projects using Pydantic v2.
- [RAGAS cookbook to evaluate RAG pipelines](https://langfuse.com/changelog/2023-10-30-ragas-cookbook.md): RAGAS is an open-source package focused on evaluating RAG pipelines. With this new cookbook, you can use RAGAS evals on your production data in Langfuse.
- [Day 1 support for GPT-4 Turbo](https://langfuse.com/changelog/2023-11-06-support-for-gpt-4-turbo.md): Accurate token counts and costs for GPT-4 Turbo
- [Support for Langchain Expression Language (LCEL)](https://langfuse.com/changelog/2023-11-13-support-for-langchain-expression-language.md): LangChain Expression Language, or LCEL, is a declarative way to easily compose chains together. Langfuse natively supports the new expression language.
- [Improved UI for OpenAI Chat Messages](https://langfuse.com/changelog/2023-11-15-pretty-generations.md): The JSON viewer is flexible but not super simple to read. Starting with OpenAI Chat Messages you can now view payloads in a pretty format to read and debug even faster.
- [Semantic releases](https://langfuse.com/changelog/2023-11-15-semantic-releases.md): Langfuse now uses semantic versioning to increase the quality of the releases.
- [More robust docker image](https://langfuse.com/changelog/2023-11-19-more-robust-docker.md): Removed cron job used for telemetry to increase stability of the docker image.
- [Change column visibility](https://langfuse.com/changelog/2023-12-04-column-visbility.md): All tables in Langfuse include lots of columns. You can now customize them to your workflow by hiding the ones you don't need.
- [Rename and transfer projects](https://langfuse.com/changelog/2023-12-12-rename-and-transfer-projects.md): In the project settings you can now rename and transfer your project.
- [Customizable sorting for trace table](https://langfuse.com/changelog/2024-01-02-sort-trace-table.md): Finally, you can choose how to sort your trace table to find the slowest, fastest, or oldest traces with ease.
- [LlamaIndex integration (Python)](https://langfuse.com/changelog/2024-02-27-llama-index-integration.md): Automatically capture detailed traces and metrics for every request of your LlamaIndex application with the new Langfuse Integration.
- [Upto 50x faster loading time of UI tables](https://langfuse.com/changelog/2024-02-29-performance-improvement-ui.md): Previously, the tables loaded very slowly depending on the project size and the kind of ingested data. I used the leap day to tweak queries and indexes to fix this.
- [Uptrain.ai integration (cookbook)](https://langfuse.com/changelog/2024-03-05-uptrain-integration.md): Langfuse adds >20 open source evaluators through cookbook integration with open source project and fellow Y Combinator startup UpTrain.ai
- [Improved ChatML message rendering](https://langfuse.com/changelog/2024-03-11-improved-chatml-rendering.md): Extending the "Pretty ✨" mode to additional json content included in ChatML messages such as functions and tools. Previously, Langfuse rendered these messages in plain json.
- [Support for LangChain async, batch and streaming interfaces](https://langfuse.com/changelog/2024-04-08-langchain-streaming-and-batch.md): With this release, Langfuse Tracing integrates natively with all LangChain interfaces on Python and JS.
- [ISO 27001 certification](https://langfuse.com/changelog/2024-04-10-ISO-27001-certification.md): Langfuse's Information Security program has been certified to the ISO 27001:2022 standard.
- [Docker images on Docker Hub](https://langfuse.com/changelog/2024-04-13-images-on-docker-hub.md): From now on, we will publish Docker images on Docker Hub and the GitHub Container Registry.
- [OpenAI SDK integration for JS/TS SDK](https://langfuse.com/changelog/2024-04-21-openai-integration-JS-SDK.md): Langfuse now provides a simple to adopt wrapper for the OpenAI JS/TS SDK for you to seamlessly trace your OpenAI calls.
- [PostHog integration](https://langfuse.com/changelog/2024-04-22-posthog-integration.md): We teamed up with PostHog to integrate LLM-related product metrics into your existing PostHog dashboards.

- [Prompt Version Insights](https://langfuse.com/changelog/2024-05-16-prompts-version-insights.md): Compare metrics across different prompt versions in Langfuse Prompt Management.
