# Integrations Overview

> Learn about the Galileo integrations with third-party SDKs to automatically log your applications

Galileo's third-party SDK integrations automatically capture prompts, responses, and performance metrics without requiring you to add explicit logging code throughout your application.

## Supported frameworks

Galileo supports a range of LLM and agentic frameworks, either with a direct integration, using [OpenTelemetry](https://opentelemetry.io/), or using [OpenInference](https://github.com/Arize-ai/openinference).

| Framework | Supported integrations |
| :- | :- |
| A2A Protocol | [`galileo-a2a`](https://docs.galileo.ai/sdk-api/third-party-integrations/a2a) |
| CrewAI | [CrewAI Event Listener](https://docs.galileo.ai/sdk-api/third-party-integrations/crewai/crewai.md) [OpenInference](https://docs.galileo.ai/sdk-api/third-party-integrations/opentelemetry-and-openinference.md) |
| Google ADK | [OpenInference](https://docs.galileo.ai/sdk-api/third-party-integrations/opentelemetry-and-openinference/google-adk.md) |
| LangChain/LangGraph | [LangChain callback](https://docs.galileo.ai/sdk-api/third-party-integrations/langchain/langchain.md) [OpenInference](https://docs.galileo.ai/sdk-api/third-party-integrations/opentelemetry-and-openinference.md) |
| OpenAI | [OpenAI SDK wrapper](https://docs.galileo.ai/sdk-api/third-party-integrations/openai/openai.md) |
| OpenAI Agents SDK | [OpenAI Agents trace processor](https://docs.galileo.ai/sdk-api/third-party-integrations/openai-agents/openai-agents.md) |
| Microsoft Agent Framework | [OpenTelemetry](https://docs.galileo.ai/sdk-api/third-party-integrations/opentelemetry-and-openinference/microsoft-agent-framework.md) |
| Strands Agents | [OpenTelemetry](https://docs.galileo.ai/sdk-api/third-party-integrations/opentelemetry-and-openinference/strands-agents.md) |
| Vercel AI SDK | [OpenTelemetry](https://docs.galileo.ai/sdk-api/third-party-integrations/opentelemetry-and-openinference/vercel-ai.md) |

These frameworks have been tested and are fully supported. Galileo also supports any framework that supports the [OpenInference](https://github.com/Arize-ai/openinference) standard.
