# Confident AI Documentation

> Documentation for Confident AI, an AI quality platform built for enterprise teams to standardize evals and observability across the organization. Confident AI also builds and maintains DeepEval, the open-source LLM evaluation framework, and DeepTeam, the open-source LLM red teaming framework; the platform's metrics are DeepEval's metrics.

Every page below is also served as HTML at the same URL without the .md suffix. The full corpus in one file is at https://www.confident-ai.com/llms-full.txt.
